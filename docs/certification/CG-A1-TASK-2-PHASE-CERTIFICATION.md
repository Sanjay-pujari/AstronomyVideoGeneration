# CG-A1 Task 2 — Phase 1–7 Artifact and Phase Certification

Task 2 adds the family-independent certification layer for RC2 Phase 1–7 production outputs. The implementation remains read-only: it verifies existing generated artifacts and returns in-memory `PhaseCertificationResult` values without rewriting production validation files.

## Added components

- `PhaseArtifactRegistry` maps each RC2 phase to the artifacts currently generated by orchestration.
- `CertificationArtifactVerifier` checks existence, non-empty files, and JSON parseability.
- `CertificationJsonReader` provides shared safe JSON document loading helpers.
- `CertificationStatusAggregator` centralizes common status aggregation rules.
- `Phase1Certifier` through `Phase7Certifier` produce structural phase certification results.
- `AddCgA1PhaseCertification()` registers the Task 2 services and is called by `AddCgA1CertificationFoundation()`.

## Scope boundaries

Task 2 does not add family-specific profiles, semantic evidence extraction, certification coordination, report writers, pipeline integration, or dashboard generation. Those remain future Task 3/4 work.

## Artifact authority

Existing `validation/phase-XX-validation.json` files are treated as production artifacts and are not modified by certification. Certification results are returned in memory only.
