# WeeklySkyForecast v2 Phase 1C: Cinematic Editorial Refinement

## Purpose
Convert the structured Phase 1B editorial package into a human, cinematic, production-ready weekly story blueprint for narration and visual planning.

## Core Rule
The final story must sound human and cinematic, not like technical metadata.

## Cinematic Storytelling Rules
- Anchor the week around one hero sky story.
- Use spoken-language framing and viewer-facing benefit.
- Keep a wide-to-detail progression (weekly overview -> best night -> object highlights).

## Repetition Collapse Rules
- If the same object set repeats across dates, collapse to one hero story.
- Keep one hero beat, one hero short, and one hero cinematic moment for that grouping.
- Preserve extra dates as supportingDates, not separate duplicated beats.

## Headline Style Rules
- Mention hero objects when available.
- Must avoid technical phrases: same viewing window, grouping event, visibility momentum.
- Must not imply conjunction/alignment unless angular separation data supports it.

## Hook Style Rules
- Spoken and curiosity-driven.
- Actionable opening (e.g., where/when to look).
- No metadata-style phrasing.

## Narrative Beat Rules
- Produce 6-7 distinct beats: Hook, Hero Story, Why It Matters, Best Night, Highlight, Tip, CTA.
- No one-beat-per-date repetition.

## Cinematic Moment Rules
- Produce 4-5 unique moments max.
- Include uniqueness key per moment (`visualUniquenessKey`).
- Recommended pattern: hero grouping, best-night wide, planet asset, moon asset, thumbnail composition.

## Shorts Uniqueness Rules
- Exactly 3 shorts:
  1. Hero event short
  2. Best observation night short
  3. Moon/planet highlight short
- Titles and hooks must be unique.

## Thumbnail Language Rules
- Max 2 title text candidates.
- Clear object hierarchy (primary/secondary objects).
- Emphasize emotional urgency and clarity without overcrowding.

## Wording Safety Rules
For source `same_window_grouping_only_no_angular_separation`:

Allowed wording:
- share the same evening sky
- appear in the same viewing window
- look west after sunset
- form the week's strongest visual grouping

Forbidden wording (unless angular separation exists):
- conjunction
- exact alignment
- rare alignment
- very close together
- almost touching
